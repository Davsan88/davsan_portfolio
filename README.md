## 🚀 Project Overview

I created this site by adapting [Cleanfolio](https://github.com/rjshkhr/cleanfolio), an open-source React portfolio template by Raj Shekhar. I moved the template into a fresh Vite project and customized the content, colours, typography, icons, and project presentation to reflect my work.

The portfolio is a starting point for exploring my projects. Each featured project links to a live version and its source code.

## ▶️ Running the Project Locally

```bash
git clone https://github.com/Davsan88/my-portfolio-new.git
cd my-portfolio-new
npm install
npm run dev
```

To create a production build, run `npm run build`. Vite writes the finished site to `dist/`.
